About QuickText

QuickText by MDU — Sports Warehouse Customer Service

What is QuickText?

QuickText is a personal shortcut tool for the Customer Service team. Instead of typing the same sentences over and over, you store them as short abbreviations. Type the abbreviation, press Space or Tab, and the full text appears instantly. Then copy it into Outlook.

How to use it — step by step
1Select your profile on the home screen and enter your initials when asked (first time only).
2In the Your Message area, type a shortcut abbreviation (e.g. bjr).
3Press Space or Tab — the abbreviation expands instantly into the full text.
4You can combine multiple shortcuts — type one, expand, type another, expand, add your own text.
5When your message is ready, click Copy all and paste into Outlook with Ctrl+V.
Shortcut types
Fixed text Any static sentence, greeting, signature or template. Always expands to exactly the same text.
Date + initials Expands to today's date and your initials automatically — e.g. 26.06.26 mdu. Updates every day.
Date only Today's date only — e.g. 26.06.26.
Date + time Today's date and current time — e.g. 26.06.26 14:35.
Tips
Use the Quick Insert buttons below the message area to insert a shortcut with one click — no typing needed.
Click Show full on any shortcut card to read its complete content before using it.
Use Export regularly to back up your shortcuts. If you change device or browser, use Import to restore them.
Use {date} anywhere inside a fixed-text shortcut to insert today's date dynamically.
Your shortcuts are saved in this browser only. Always use the same browser on the same device. Do not use private/incognito mode.
If you need a profile renamed, initials changed, or a new colleague added, contact the Manager (MDU).
